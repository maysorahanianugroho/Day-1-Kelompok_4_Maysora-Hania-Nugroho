# Rangkuman Materi Workshop Day 1
## Building with AI, Managing Change with GitHub

### 1. Prompt Engineering

Prompt Engineering adalah cara membuat instruksi yang diberikan kepada AI supaya AI bisa memberikan jawaban sesuai dengan apa yang kita butuhkan.

**Apa itu Prompt AI?**

Prompt adalah perintah atau pertanyaan yang kita berikan kepada AI untuk mendapatkan hasil tertentu. Prompt bisa berupa pertanyaan singkat, kata kunci, atau instruksi yang lebih lengkap.

**Cara Membuat Prompt yang Baik**

Ada empat bagian yang perlu diperhatikan saat membuat prompt:

- **Role:** Menentukan AI harus berperan sebagai apa.
- **Task:** Menjelaskan tugas yang ingin dikerjakan.
- **Context:** Memberikan informasi tambahan supaya AI lebih memahami permintaan kita.
- **Format:** Menentukan bentuk jawaban yang kita inginkan.

**Manfaat Prompt Engineering:**
- Membantu AI memberikan hasil yang lebih sesuai.
- Mengurangi jawaban yang kurang tepat atau mengandung bias.
- Membuat kita lebih mudah mengatur hasil yang diberikan AI.
- Membantu mendapatkan pengalaman penggunaan AI yang lebih baik.

### 2. Mengenal Git dan GitHub

**Apa itu Git?**

Git adalah alat yang digunakan untuk mencatat perubahan pada file atau proyek. Jadi, kita bisa mengetahui perubahan apa saja yang sudah dilakukan dan kapan perubahan tersebut terjadi.

Git dibuat oleh Linus Torvalds pada tahun 2005.

**Apa itu GitHub?**

GitHub adalah website yang digunakan untuk menyimpan proyek Git secara online. Selain itu, GitHub juga bisa digunakan untuk bekerja sama dengan orang lain.

**Perbedaan Git dan GitHub:**

- Git digunakan untuk mencatat dan mengatur perubahan pada proyek.
- GitHub digunakan untuk menyimpan proyek tersebut secara online dan memudahkan kolaborasi.

### 3. Git Workflow

Dalam Git, ada tiga bagian yang perlu diketahui:

1. **Working Directory:** Tempat kita mengerjakan dan mengubah file proyek.
2. **Staging Area:** Tempat menyiapkan file yang perubahannya ingin disimpan.
3. **Git Directory:** Tempat Git menyimpan informasi dan riwayat perubahan proyek.

### 4. Perintah Dasar Git

Selama workshop, ada beberapa perintah Git yang diperkenalkan:

| Perintah | Fungsi |
|---|---|
| `git init` | Membuat repository Git baru. |
| `git add .` | Menyiapkan perubahan file untuk disimpan. |
| `git add --all` | Menyiapkan semua perubahan file. |
| `git commit -m "message"` | Menyimpan perubahan dengan pesan tertentu. |
| `git remote add <name> <url>` | Menghubungkan proyek dengan repository online. |
| `git push origin main` | Mengirim perubahan proyek ke GitHub. |
| `git pull origin main` | Mengambil perubahan terbaru dari GitHub. |
| `git clone <url>` | Mengunduh salinan repository ke komputer. |

### 5. Git dan VS Code Setup

Sebelum menggunakan Git, kita perlu menginstalnya terlebih dahulu sesuai dengan perangkat yang digunakan.

Ada beberapa perintah yang bisa digunakan untuk mengecek dan mengatur Git.

**Mengecek versi Git:**
```bash
git --version
```

**Mengatur nama dan email pengguna:**
```bash
git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
```

**Mengecek pengaturan Git:**
```bash
git config --global --list
```

Selain Git, workshop juga memperkenalkan VS Code sebagai aplikasi untuk menulis dan mengedit kode.

### 7. Praktik: Student Task Planner

Pada bagian praktik, peserta diperkenalkan dengan pembuatan aplikasi sederhana bernama Student Task Planner.

Aplikasi ini dibuat dengan bantuan AI. Berikut tahapan yang dijelaskan dalam materi:

1. Menggunakan platform AI seperti ChatGPT, Claude, atau Antigravity.
2. Membuat prompt untuk meminta AI membuat aplikasi.
3. Menambahkan proyek ke Git menggunakan `git init`.
4. Menyimpan perubahan dengan commit dan mengirimkannya ke GitHub.
5. Melakukan perubahan pada proyek.
6. Melakukan commit dan push kembali setelah ada perubahan.
